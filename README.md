# Yutkin rebar recovery — open concept

Concept of a machine that breaks reinforced concrete with electrohydraulic shocks in water (the Yutkin effect) and recovers the rebar whole and straight for reuse. The concrete goes to crushed stone.

Концепция установки, которая разрушает железобетон электрогидравлическим ударом в воде (эффект Юткина) и извлекает арматуру целой и ровной для повторного использования.
